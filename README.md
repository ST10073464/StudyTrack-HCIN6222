# StudyTrack

StudyTrack is a responsive academic assessment management prototype developed for the HCIN6222 Human Computer Interaction Portfolio of Evidence.

## Purpose

StudyTrack helps tertiary students:

- Manage academic assessments
- Monitor approaching deadlines
- Track assessment progress
- Search and filter assessments
- Receive accessible validation and system feedback
- Access the interface across desktop and mobile devices
