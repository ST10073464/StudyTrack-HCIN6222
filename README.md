# StudyTrack – HCIN6222

StudyTrack is a responsive academic assessment and deadline management prototype developed for the Human Computer Interaction (HCIN6222) Portfolio of Evidence.

## Project Overview

StudyTrack helps tertiary students organise and monitor academic assessments and deadlines from one accessible interface.

The prototype was developed from the interaction design planning completed during Part 1 and Part 2 of the HCIN6222 Portfolio of Evidence.

## Main Features

- Responsive student dashboard
- Assessment summary and deadline indicators
- Add assessments
- View assessment details
- Edit assessments
- Delete assessments with confirmation
- Mark assessments as started or completed
- Search assessments
- Filter by module
- Filter by status
- Assessment sharing
- Persistent browser storage
- Accessible form validation
- System feedback messages
- Responsive mobile navigation

## Data Storage

StudyTrack uses browser local storage to persist assessment information.

The prototype does not require a database or user account.

## Continuous Integration

GitHub Actions is used to automatically run project quality checks when changes are pushed to the repository.

The CI workflow includes JavaScript linting using ESLint.

## Responsive Design

StudyTrack has been tested at desktop and mobile viewport sizes.

The interface adapts its:

- Navigation
- Dashboard cards
- Assessment cards
- Forms
- Search and filters
- Action buttons
- Assessment details
- Delete confirmation interface

for smaller screens.

## Running Locally

Clone the repository and open the project in Visual Studio Code.

The prototype can be run using the Live Server extension by opening `index.html`.
